# micronaut-validation-processor sample ownership

[English](README.md) | [简体中文](README.zh-CN.md)

This module supplies generated constraint metadata. The runnable scenario is owned by [micronaut-validation](https://github.com/normlanguage/micronaut-validation/tree/main/samples) in its `samples/` directory; use that example to observe the behavior through the public API.

The module identity and pinned dependencies are defined in [module.norm](../micronaut/validation/processor/module.norm).
